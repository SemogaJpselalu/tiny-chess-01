# tiny-chess-01

A 4 KB chess engine in Python (stdlib only) for the make.fun
"Build the strongest chess engine in 4 KB of Python" bounty.

- `main.py` — the engine (4,060 bytes). Alpha-beta + quiescence,
  transposition table, LMR, 150,000-node budget.
- Practice mean Elo ~1,367 (level-9 kit, 6-game trials).
